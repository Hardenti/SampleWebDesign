# Secure Campus Network

This is a polished single-page product concept designed to represent a nuclear security and college engagement initiative. It frames the brand around stakeholder outreach, educational programming, workforce development, and trusted communication between academic institutions and nuclear security leaders.

## Files

- index.html — page structure and content
- styles.css — visual design and responsive styling
- script.js — small script for dynamic year display

## How to preview

Open index.html directly in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then open: http://localhost:8000/
